# Synthetic phantom

A self-contained frame set with known reference poses, generated by
`make_phantom.py`. It uses no clinical data.

`make_phantom.py` defines an analytic three-dimensional medium: a skin layer, a
fascial layer, a spherical target with a bright rim and a fixed speckle texture.
Sixteen frames are sampled at 1 mm spacing over a 15 mm sweep, exactly as
`model.render` samples them.

| Property | Value |
| --- | --- |
| Frames | 16, at 1 mm spacing over a 15 mm sweep |
| Image size | 128 x 96 pixels |
| Pixel spacing | 0.25 mm lateral, 0.5 mm axial |
| Depth range | 0 to 48 mm |

The file order is deliberately not the scan order: the frames of a set need not
arrive in acquisition order.

## Files

```text
examples/phantom/
├── make_phantom.py     # regenerates data/ and config.json
├── config.json         # sampling and optimisation settings
├── checkpoint.pt       # a fitted checkpoint
└── data/
    ├── images/         # 0.png through 15.png
    ├── class.npy       # group assignment
    ├── similarity.npy  # pairwise similarity
    └── poses.npy       # reference poses, evaluation only
```

## Run the example

From the repository root:

```bash
# 1. render the checkpoint and score it against the frames
python demo.py \
  --checkpoint examples/phantom/checkpoint.pt \
  --config examples/phantom/config.json \
  --data examples/phantom/data \
  --output runs/phantom

# 2. pose accuracy and SSIM against the reference poses
python evaluate.py \
  --data examples/phantom/data \
  --results runs/phantom
```

Without `--data`, `demo.py` renders the frames without the image metrics.

The reference poses in `data/poses.npy` are the 16 planes at their nominal
1 mm spacing. `evaluate.py` reports the error after expressing both trajectories
relative to the same alignment frame.
